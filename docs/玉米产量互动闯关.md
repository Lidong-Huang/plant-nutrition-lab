# 这次玉米产量显著提高了吗？

以2024级农资班为场景，历史长期均值500公斤/亩为预先给定基准。示例四个独立小区为520、540、560、580公斤/亩。学生完成操作与选择后才能逐步解锁，回看不受限制。

## 五幕与十五个任务

1. 历史收获：先展示48块示意历史小区，再汇总240条单个小区亩产记录；第二次点击将同一批数值按产量段分组，散点汇入柱子，最后叠加正态模型。完成历史阶段后才进入本次四个试验小区。
2. 四个小区：逐块收获与称重、计算均值、保留初判。每个小区示例面积20m²；称得15.60、16.20、16.80、17.40kg，折合相应亩产。四个小区为独立重复，同一小区的多株不是独立重复。
3. 均值的波动：先明确没有提高的基准假设，四个独立小区来自同一历史正态模型，再模拟至少三次四重复试验；每四个观测形成一个实际算术均值。比较n＝1、4、16，共用横轴与密度纵轴。解释更集中表示均值估计更稳定、更精确，显著与否还取决于增幅相对误差的大小。
4. 标准化与概率：从需要计算右尾积分引出共用标准正态积分表；演示550→50→2.50且右尾概率保持不变，再点击表中行2.5、列0.00，读取0到z面积0.4938，用0.5相减得到右尾0.0062。需要查对单元格、算对面积并理解标准化作用才能继续。随后明确“实际试验总体标准误差未知”，由四个小区估计分母；比较至少三组估计的分母，引出t；比较不同重复数n；计算实际t值、右尾概率并判断其含义。
5. 作出判断：按预先约定的α判断；用同均值、不同离散程度的数据完成迁移练习。最后显示完成页并支持下载匿名学习记录。

未完成必要操作、动画或判断题时，下一步和后续幕被禁用。初判没有正确答案，任一选择可继续；概念题与结论题答错可重试。没有跳关、自动播放或教师口令绕过。进度仅保存在本浏览器的专用localStorage条目中；不可用时仍可在本次会话学习。重新开始仅清除这项课程进度，记录不自动上传。

当前为第4版教学流程，使用独立的v4进度条目；旧版进度保留在原条目中。本版保留Gosset分布比较，将自由度简化为一个固定例子，U与t改用简短数学对照；自由度不再要求拖动、确认或专门答题。

## Gosset、自由度与综合试验页

- 第9步先逐组比较至少三次同源的U与T，再累积到1000组真实算术结果；按样本数和组距作密度直方图，±2之外的频率包含全部样本，画布之外的结果单独记账。学生先比较尾部，再点击显示理论t曲线。理论曲线不从观察频率反推或拟合。
- 使用同一组独立正态观测，U＝(x̄−500)/(40/√n)，T＝(x̄−500)/(s/√n)。蓝色U标注已知分母σ/√n，橙色T标注估计标准误差s/√n。每组s采用n−1作分母，与t分布自由度相符。
- 历史依据是Gosset将3000份资料写到卡片、打乱并分成750组四个样本作比较。本课改用合成玉米数据和现代记号重现比较思路，不冒充原始试验或其原始统计量。
- 自由度只用固定例子520、540、560、580，均值550，对应偏差−30、−10、＋10、＋30。四个偏差和为0，前三个合计−30后，第四个必须为＋30，因此df＝4−1＝3。无需操作这组偏差，也不设置自由度专门考题。Gosset页仍需要完成两套分布比较与t分布识别题。
- 第10步仅保留两栏公式和一幅标准正态/t曲线对照，去掉点云、估计误差散点、三组区间变换与相关动画开关。改变n只更新自由度、同一正阈值2的右尾和t方差示例。
- 数学设定仍为正态总体和独立重复：X̄∼N(μ,σ²/n)。固定n时，U的分母σ/√n为已知定值；中心化后期望为0，Var(U)＝(σ²/n)÷(σ²/n)＝1。线性变换保持正态，因此U∼N(0,1)，形状不再以n作参数。此结论不是只凭均值0、方差1推断正态，也不表示同一个观测对应的U数值不随n变化。
- T＝(X̄−μ)/(s/√n)＝U×σ/s，额外随机比值σ/s随样本量变化，分布由df＝n−1区分。页面用已知t分布的方差结果Var(T)＝(n−1)/(n−3)（n＞3）直接说明其分布仍依赖n；这是引用的方差结果，不把它冒充由前一行代数式直接推出的结论。n＝4时方差3，n＝100时约1.0206；与U的方差1比较。推导不展开卡方、Gamma函数或t密度积分。
- 第12步将低尾、中间和本次及更高尾部分成蓝、绿、橙三色。第13步采用“同类分布”的课堂表述，参照历史基准500的条件保留在图例与说明中。
- 第15步改成“我们再做一批试验”：学生收获490、530、570、610四个小区，左侧四块区域分别呈现小区与亩产、均值/标准差/SE、t分布与点的右尾概率、显著性结论。计算与结论都使用这批数据，第一批资料作为对照提示，不混用其SE。

## 数值与统计模型

- 本例假定独立小区产量服从正态分布。四个点本身不足以验证正态性。
- 首幕历史记录来自固定、成对对称且打乱顺序的教学样本，均值精确为500、总体标准差40；不冒充真实历年调查数据。直方图由这240个数实际分组计数，含越界记账，不使用预画的钟形柱高。
- 历史均值500作为固定基准，不包含历史均值估计的不确定性。实际跨年比较还需处理条件可比性和历史估计误差，不能单凭该比较将差异全部归因于处理。
- 实际试验总体σ未知，使用样本标准差：x̄＝550，s≈25.819889，估计SE≈12.909944，t≈3.872983，df＝3。
- 提高方向和α＝0.05在查看结果前约定，使用右尾单样本t检验：p≈0.015233；临界值≈2.353363。p＜α，表述为相较历史基准显著偏高，仍有误判风险。
- 抽样与已知σ的U动画专门设定σ＝40，仅演示规律。均值分布标准差为40/√n，与实际四个小区估计的s/√n区分。正态总体下均值抽样分布本身仍是正态；服从t分布的是以样本估计标准误差作分母的统计量。
- 已知SE＝20的查表演示中，P(X̄≥550)＝P(U≥2.50)≈0.00621；它和实际未知SE后用t算出的0.01523分属两个条件。标准化期间积分上下限、概率密度和坐标单位一同变换，保留概率。积分表采用NIST的0到z面积约定，0.4938不是整段左侧累计概率。标准化方便不同正态分布共用数值积分表，并非现代数值积分的数学必要条件。
- t密度、CDF和分位数调用既有StudentTMath，不用正态近似；t分布不具有统一为1的标准差。
- 练习数据490、530、570、610的均值仍为550，s≈51.639778，SE≈25.819889，t≈1.936492，右尾p≈0.074110。未发现显著提高的证据，不等于证明没有效果。
- 直方图按样本数与组距归一化为概率密度；所有记录保留用于归一化。概率使用CDF到正无穷的完整右尾，不把画布截断位置当积分终点。
