# 霍格兰配液、磁力搅拌与 pH 管理

课件：[水培 · 霍格兰供磷试验](https://lidong-huang.github.io/plant-nutrition-lab/lessons/hydro-culture.html)。配液实验台位于第二步，pH 测定和可点击通气开关位于第六步。

## 配方版本与用量

主要依据本地《植物营养研究法电子书.docx》表 1-9 的霍格兰营养液（一）。其大量元素原方为 KNO₃ 5、Ca(NO₃)₂ 5、MgSO₄ 2、KH₂PO₄ 1 mmol/L。本研究场景用**改良半量背景**，再改变 P 并以 KCl 补钾；不得把改良液标为未经修改的全量原方，也未混用含 NH₄H₂PO₄ 的营养液（二）。

| --- | ---: | ---: | ---: |
| KNO₃ | 0.505516 | 0.252758 | 1.263790 g |
| Ca(NO₃)₂·4H₂O | 1.180745 | 0.590372 | 2.951861 g |

### 磷处理及补钾，配 5 L

| 项目 | P₀ | P₁ | P₂ |
| --- | ---: | ---: | ---: |
| 最终 P，mmol/L | 0 | 0.05 | 0.50 |
| 0.1 mol/L KH₂PO₄ 母液 | 0 mL | 2.50 mL | 25.00 mL |
| 0.1 mol/L KCl 母液 | 25.00 mL | 22.50 mL | 0 mL |

每 100 mL 0.1 mol/L 母液分别用 KH₂PO₄ 1.360855 g、KCl 0.745513 g，分别溶解、定容和标记。小用量采用经过核算的母液移取，不把数毫克磷盐画成随意直接称量。工作液总 K=3.00、硝态 N=7.50、Ca=2.50、Mg=1.00 mmol/L。Cl⁻ 随补钾改变；配平这些大量元素不等于所有阴离子都相同。

### 铁与微量元素

原表采用酒石酸铁 0.005 g/L；本例改为 Fe-EDTA，按 Fe 25 µmol/L，不能按相同药品质量替换。Fe 母液与其他母液分开，按 Fe 10 mmol/L 配置，5 L 工作液移取 12.50 mL。配制 Fe 母液时需核对实际产品含 Fe 质量分数；每升母液应含 Fe 0.55845 g，产品质量为 0.55845÷含 Fe 质量分数（g），不能在未核对产品成分时固定称取一种商品质量。

## 六个配液镜头与操作条件

1. **配方核对**：显示试剂瓶、原方与本批用量表，核对体积、处理和结晶水。改变体积或处理会重置当前配制记录。
2. **准确称量**：称量纸先去皮，再加入当前药品的目标质量。图中为带防风罩的天平，示意显示至 0.0001 g，不表示实际仪器已检定达到此精度。
3. **磁力溶解**：称好的一项药品用部分去离子水在烧杯中溶解。可按磁力搅拌器旋钮或底部按钮；磁子旋转、晶体逐渐消失。只使用搅拌，不加热。固定约 3 秒溶解仅为课堂节奏，不是盐的真实溶解动力学。
4. **转移洗涤**：确认溶解后停搅拌、取出磁子，再沿玻棒、经漏斗转入容量瓶。清洗烧杯与玻棒，将洗液一并转入；本课以 3 次作为操作演示。完成当前药品后，再按同样流程处理下一种大量元素。容量瓶中保留足够余量，洗液、母液及后续调节液体均计入终体积。
5. **母液移取**：三种大量元素都已定量转移后，分别移取本处理的磷、补钾、微量元素及铁母液。浓钙液不与浓磷液直接相混；在足够稀释并混匀的水相中依次加入。小体积应选合适量程和精度的移液器具。
6. **定容混匀**：按试验方案检查并调 pH，确认溶液恢复室温后，最后补水至刻度。平视凹液面最低点与刻度相切，封塞后倒转混匀，标记处理、日期和配方版本。不是先装满规定体积的水再加入药品。图中瓶体几何、倒转与液体形状为教学简化，不代替真实容量器具检定。

界面会阻止未称量就完成溶解、未溶解就转移、漏掉洗液就进入下一药品、未加入母液就直接定容等操作。主步骤可以切换观察，但切换画面不会自动补齐尚未完成的人工操作。自动演示另按顺序完成这些动作。

## pH 测定与通气

培养装置上的气泵开关和底部“通气”按钮均可点击；开机恢复气流与液中气泡，关机停止。pH 测定使用取出的小份样液，避免把标准缓冲液或测量后的样液倒回培养槽。

采用 25°C 下 pH 7.00、4.01 两点缓冲液，包围示例样液的 pH 范围。流程为：

1. 冲洗电极，放入新鲜小份 7.00 缓冲液；浸没敏感端和液接界，稳定后确认。
2. 再次冲洗，放入 4.01 缓冲液，稳定后确认第二点。
3. 冲洗后浸入本处理的小份样液，避免气泡附着，保持校准与测量条件一致。
4. 待读数稳定后记录 pH 与温度。课件值 **6.08、25°C 为教学模拟**，不由施磷量预测，也不是真实样液的测定结果。约 1.1 秒稳定是操作演示时间，不是仪器响应指标。
5. 换液后重新取样测定；同次有效校准可继续使用，但真实试验需按仪器规程检查校准有效性。电极清洁、保存与维护遵循厂家要求，避免损伤敏感玻璃。

未完成两点校准时不能记录样液结果，未稳定也不能确认校准或记录。pH、EC、磷浓度分别记录，不能互相替代。真实研究还需评估 pH 调节所引入的副离子及不同处理的缓冲差异。
