# 正态分布：标准化、累积概率与积分

保留原有形状、对称、均值、标准差、拐点和概率六步，增加以下三步。

| 步骤 | 画面 | 核心联系 |
| --- | --- | --- |
| 标准化 | 三组对应刻度、同一观测值沿步骤移动 | X → Y=X−μ → Z=Y/σ；先改变原点，再改变单位。 |
| 累积概率 | 左侧密度阴影、右侧累积分布点同步变化 | 阴影面积等于 Φ(z) 的高度，不是密度 φ(z) 的高度。 |
| 积分 | 8、24、64、160 个中点矩形逐个累加 | 每块面积 φ(tᵢ)Δt；加上未画的左尾后，逼近 Φ(z)。 |

## 标准化

在 X 服从 N(μ,σ²)、σ>0 的条件下：

$$Y=X-\mu\sim N(0,\sigma^2),\qquad Z=\frac{X-\mu}{\sigma}\sim N(0,1).$$

例如 μ=200、σ=20、x=220，先减均值得 20，再除以标准差得 z=1。此时

$$P(X\le220)=P(Y\le20)=P(Z\le1)=\Phi(1)\approx0.841345.$$

三图使用不同的横轴单位和密度刻度；形状绘在相同标准差范围内，便于对照。中心化不改变 σ；标准化使标准差变成 1。原密度峰值约为 0.0199，标准化后约为 0.3989；数值高度不同，概率仍相等，因为

$$f_X(x)\,dx=\varphi(z)\,dz,\quad dx=\sigma\,dz,\quad f_X(x)=\varphi(z)/\sigma.$$

标准化任意分布并不会自动把它变为正态。本例从正态变量出发；若 μ、σ 由样本估计，还要区分总体标准化与样本计算，不能据此直接推断所有统计量都为标准正态。

## 累积概率与积分

$$\varphi(t)=\frac{1}{\sqrt{2\pi}}e^{-t^2/2},\qquad \Phi(z)=P(Z\le z)=\int_{-\infty}^{z}\varphi(t)\,dt.$$

拖动同一个 z，同步改变密度图中的边界、阴影面积和累计曲线上的点 (z,Φ(z))。Φ 单调增加并趋近 1；φ 是概率密度，其纵坐标不是某个单点的概率。连续变量 P(Z=z)=0。

累计概率与原变量的关系为

$$P(X\le x)=\Phi\!\left(\frac{x-\mu}{\sigma}\right),\qquad P(a<X\le b)=\Phi\!\left(\frac{b-\mu}{\sigma}\right)-\Phi\!\left(\frac{a-\mu}{\sigma}\right).$$

积分变量 t 是累加位置；z 是积分上限。两者不混用。预设 z=−1.96、0、1.96 对应累计概率约 0.025、0.5、0.975；中央约 95% 是两端累计概率之差，不是 Φ(1.96) 本身。原“中央 95%”按钮继续使用精确正态分位数 1.95996398454。

## 积分动画与数值范围

为让矩形可见，画面显示标准坐标 −4 到 4，界限滑块为 −3 到 3。密度和累计函数的定义域并未被截断。

将 [−4,z] 分成 n 段，Δt=(z+4)/n，取各段中点 tᵢ：

$$\Phi(z)=\Phi(-4)+\int_{-4}^{z}\varphi(t)\,dt\approx\Phi(-4)+\sum_{i=1}^{n}\varphi(t_i)\Delta t.$$

其中未显示的左尾 Φ(−4)≈0.00003167 已加到累计数值中。动画显示已累加 k/n、矩形和加左尾、以及独立计算的 Φ(z)，使近似值与目标值可比较。矩形分割变细会收敛，但一般不应把所有数值积分方法的逐次误差都理解为严格单调下降。

正态 CDF 用误差函数的数值近似计算，检查包含标准概率基准、Φ′=φ、单调性、概率面积和密度换元。数学公式使用浏览器原生 MathML，无需在线加载公式库；离线版包含脚本与样式。三幅曲线的旋转是观察视角，不引入额外的随机变量。
