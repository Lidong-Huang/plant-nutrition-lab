# 正态分布：抽样分布、两者标准化、累积概率与积分

知识路径为：形状 → 对称 → 拐点 → 概率 → 抽样分布 → 分布比较 → 两者标准化 → 累积概率 → 积分。均值和标准差不再设置独立过程，μ、σ 参数仍可用于探索。

| 步骤 | 画面 | 核心联系 |
| --- | --- | --- |
| 抽样分布 | 从总体抽取 n 个点，汇成一个均值点，反复累积直方图 | 每组样本只提供一个样本均值；虚线表示理论抽样分布。 |
| 分布比较 | 在同一横轴和密度刻度上叠加 X 与 X̄ 的密度 | 共同期望 μ；标准差分别为 σ 与 σ/√n。 |
| 两者标准化 | 两组曲线同步中心化、缩放，最终叠加 | X 除以 σ，X̄ 除以 σ/√n；最终均为 N(0,1)。 |
| 累积概率 | 左侧密度阴影、右侧累积分布点同步变化 | 阴影面积等于 Φ(z) 的高度，不是密度 φ(z) 的高度。 |
| 积分 | 8、24、64、160 个中点矩形逐个累加 | 每块面积 φ(tᵢ)Δt；加上未画的左尾后，逼近 Φ(z)。 |

## 独立抽样与样本均值

设 X₁,…,Xₙ 独立同分布，且 Xᵢ∼N(μ,σ²)，总体 σ 已知。每组样本的均值为

$$\overline X=\frac{1}{n}\sum_{i=1}^n X_i,\quad E(\overline X)=\mu,\quad \operatorname{Var}(\overline X)=\frac{\sigma^2}{n},\quad \operatorname{SD}(\overline X)=\frac{\sigma}{\sqrt n}.$$

因此 X̄∼N(μ,σ²/n)，对任意正整数 n 精确成立，无需把“小样本”误判为 t 分布。n=1 时两条分布重合；n 增大，样本均值更集中，但总体 X 的分布不随之改变。此处研究正态总体，不延伸为任意总体的有限样本结论。

动画使用 Box–Muller 独立生成每组 n 个正态观测，再实际求算术平均，不直接生成均值点。直方图用“频数 / 全部均值个数 / 组距”换算成密度。图示窗口外的均值保留在总数中并单独提示。修改 μ、σ 或 n 会清空旧记录，避免混合不同条件的抽样结果。“抽取一组”和“累积100组”按精确目标个数停止；连续抽样上限为5000组。

## 两者标准化

在 X 服从 N(μ,σ²)、σ>0 的条件下：

$$Z=\frac{X-\mu}{\sigma}\sim N(0,1),\qquad Z_{\overline X}=\frac{\overline X-\mu}{\sigma/\sqrt n}\sim N(0,1).$$

例如 μ=200、σ=20、n=9，x=220 对应 z=1，而样本均值 x̄≈206.667 对应 z=1。两者选择的是同一分位，原始数值不同。

$$P(X\le220)=P(\overline X\le200+20/3)=\Phi(1)\approx0.841345.$$

同步动画先减去共同期望 μ，再分别除以各自标准差。每个动画时刻，两幅图采用共同的横轴和纵轴刻度；坐标刻度随变换更新，最终两条密度叠加重合。单个观测的原密度峰值约为0.0199，样本均值的原密度峰值约为0.0598，标准化后均约为0.3989；概率面积不变，因为

$$f_X(x)\,dx=\varphi(z)\,dz,\quad dx=\sigma\,dz,\quad f_X(x)=\varphi(z)/\sigma.$$

标准化任意分布并不会自动把它变为正态。本例从正态变量出发；若 μ、σ 由样本估计，还要区分总体标准化与样本计算，不能据此直接推断所有统计量都为标准正态。

## 累积概率与积分

$$\varphi(t)=\frac{1}{\sqrt{2\pi}}e^{-t^2/2},\qquad \Phi(z)=P(Z\le z)=\int_{-\infty}^{z}\varphi(t)\,dt.$$

拖动同一个 z，同步改变密度图中的边界、阴影面积和累计曲线上的点 (z,Φ(z))。Φ 单调增加并趋近 1；φ 是概率密度，其纵坐标不是某个单点的概率。连续变量 P(Z=z)=0。

累计概率与原变量的关系为

$$P(X\le x)=\Phi\!\left(\frac{x-\mu}{\sigma}\right),\qquad P(a<X\le b)=\Phi\!\left(\frac{b-\mu}{\sigma}\right)-\Phi\!\left(\frac{a-\mu}{\sigma}\right).$$

积分变量 t 是累加位置；z 是积分上限。两者不混用。预设 z=−1.96、0、1.96 对应累计概率约 0.025、0.5、0.975；中央约 95% 是两端累计概率之差，不是 Φ(1.96) 本身。原“中央 95%”按钮继续使用精确正态分位数 1.95996398454。

## 积分动画与数值范围

为让矩形可见，画面显示标准坐标 −4 到 4，界限滑块为 −3 到 3。密度和累计函数的定义域并未被截断。

将 [−4,z] 分成 m 段，Δt=(z+4)/m，取各段中点 tᵢ；m 是积分分割数，与每组样本量 n 区分：

$$\Phi(z)=\Phi(-4)+\int_{-4}^{z}\varphi(t)\,dt\approx\Phi(-4)+\sum_{i=1}^{m}\varphi(t_i)\Delta t.$$

其中未显示的左尾 Φ(−4)≈0.00003167 已加到累计数值中。动画显示已累加 k/m、矩形和加左尾、以及独立计算的 Φ(z)，使近似值与目标值可比较。矩形分割变细会收敛，但一般不应把所有数值积分方法的逐次误差都理解为严格单调下降。

正态 CDF 用误差函数的数值近似计算，检查包含标准概率基准、Φ′=φ、单调性、概率面积和密度换元；抽样模型额外检查不同样本量的独立模拟矩、两种标准化和窗口外计数。数学公式使用浏览器原生 MathML，无需在线加载公式库；离线版包含脚本与样式。曲线旋转是观察视角，不引入额外的随机变量。
