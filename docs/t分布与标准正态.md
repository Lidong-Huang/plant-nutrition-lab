# t 分布与标准正态分布

独立课件采用正态分布资源的旋转、分步、滑块与概率面积模式，使用同一横轴和密度刻度比较两种分布。

| 步骤 | 观察内容 | 关键关系 |
| --- | --- | --- |
| 形状 | 叠加两条密度曲线 | 同以 0 为对称中心；t 的峰更低、尾更厚，总面积均为 1。 |
| 厚尾 | 放大右尾，固定同一边界 ±1.960 | 标准正态双尾约 0.05；有限自由度 t 分布的双尾概率更大。 |
| 样本量 | 同时改变 n、ν 与 t 曲线 | 本例为单样本均值情形，ν=n−1；t 的形状参数是自由度，不是样本量本身。 |
| 趋近正态 | 自动从 n=3 增至 n=201 | 随自由度增大，t 趋近 N(0,1)，不设“达到某个 n 就完全相等”的开关。 |
| 双尾 0.05 | 两幅图各取自己的中央 95% | 每尾 0.025；正态临界值约 ±1.960，t 临界值随 ν 变化。 |
| 临界值 | 同图比较区间宽度与可拖动位置 | 同一横坐标可落在一个参考区间内、另一个区间外；这不表示两种检验可任意选择。 |

## 模型

标准正态密度为 φ(x)；标准 Student t 分布的密度为

$$f_\nu(t)=\frac{\Gamma((\nu+1)/2)}{\sqrt{\nu\pi}\,\Gamma(\nu/2)}\left(1+\frac{t^2}{\nu}\right)^{-(\nu+1)/2}.$$

这里的 t 并未另行缩放为方差 1。ν>2 时方差为 ν/(ν−2)；ν≤2 时没有有限方差。ν=1 时也没有定义良好的均值，但仍关于 0 对称。因此画面使用“对称中心”，不把所有自由度的中心都称作均值。

课件把 n 映射为 ν=n−1，是以下单样本情形：独立同分布的正态观测，总体标准差未知，以样本标准差 s 估计；在原假设 μ=μ₀ 下，

$$T=\frac{\bar X-\mu_0}{s/\sqrt n}\sim t_{n-1}.$$

总体标准差已知时，相应的 Z 统计量分母用 σ/√n。配对、两独立样本、Welch 检验和回归等各有自己的自由度；不能一律使用 n−1。改变 n 不是把任意原始数据变成正态，也不是改变总体标准差。

## 双尾合计 0.05

本课件的下标使用**左侧累积概率**。设 c=t₀.₉₇₅,ν，即 P(T≤c)=0.975，则

$$P(T<-c)=0.025,\quad P(-c\le T\le c)=0.95,\quad P(T>c)=0.025.$$

双尾区域为 (−∞,−c) 与 (c,∞)，合计 0.05；不是每尾 0.05。标准正态使用 z₀.₉₇₅=1.95996398454。

| 单样本量 n | 自由度 ν | t 的上临界值（中央 95%） |
| ---: | ---: | ---: |
| 3 | 2 | 4.303 |
| 6 | 5 | 2.571 |
| 11 | 10 | 2.228 |
| 31 | 30 | 2.042 |
| 101 | 100 | 1.984 |

“厚尾”一步固定两者的边界为 ±1.960，比较所得概率；“双尾 0.05”一步则固定两者的尾部概率，比较所需边界。这两种比较不能混为一谈。

图中的中央区间是**统计量分布的参考区间**，不是原始玉米观测值范围，也不是直接针对总体均值的置信区间。满足单样本模型前提时，均值置信区间为 x̄±c·s/√n。最后一步只演示临界边界；实际检验需要使用与模型对应的统计量。

## 图形与计算

- 两幅区间图保持相同横轴范围和密度刻度。ν=1 等极小自由度下，自动扩大横轴以容纳较远的临界值，曲线因此在屏幕上显得更窄；数值密度没有改变。
- t 分布尾部较长，画面只显示有限范围。0.025 标记包括图外尾部；概率由完整 CDF 计算，未把屏幕内阴影积分冒充完整尾概率。
- PDF 使用对数 Gamma；CDF 使用正则化不完全 Beta 连分式；分位数用二分法反求，不以正态近似代替 t 临界值。
- 验证包括 ν=1 的 Cauchy 解析结果、ν=2 的解析 CDF、NIST 临界值表、PDF 数值积分、CDF 导数，以及 n=2…201 的每尾 0.025 与中央 0.95。
- 封面为代码生成的原生矢量曲线，密度及临界值取 ν=5；两张曲面分置不同深度以便辨认，课堂定量比较使用课件中的共同坐标。
