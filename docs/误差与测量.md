# 误差、准确度与精确度

本资源以本地《植物营养研究法》“试验误差与统计基础”中的真值与均值、误差概念及分类、集中与变异度量、随机误差分布为主线。将这些内容组织为七个短场景，使用打靶、读数分解和分布动画，不照搬教材长段文字。

| 场景 | 要回答的问题 | 模型与边界 |
| --- | --- | --- |
| 认识误差 | 测量值和参考值相差多少？ | 参考值 μ=50 mg P/L 是教学设定；真实样品的真值通常未知。 |
| 两类误差 | 为什么整组偏移，又逐次波动？ | xᵢ=μ+b+εᵢ；本例 b 恒定，现实系统误差也可呈比例、漂移或其他可预测变化。 |
| 打靶比较 | 集中就一定准确吗？ | 四个靶展示偏倚小/大与离散小/大的组合。样本中心并不等于总体中心。 |
| 测量值 | 一次读数如何分解？ | 总误差 b+εᵢ；随机误差可能偶然抵消系统偏差。 |
| 重复与均值 | 多测几次能解决什么？ | 独立、同分布且方差有限时，E(x̄)=μ+b，SD(x̄)=σ/√n。样本标准差 s 估计 σ，s/√n 估计均值标准误。 |
| 随机误差分布 | 所有随机误差都正态吗？ | 可选正态、均匀和右偏模型，均被标准化为总体均值 0、方差 1 后乘 σ；正态并非随机误差的普遍必然性质。 |
| 回到试验 | 怎样控制不同来源的误差？ | 校准、标准物质、空白、回收试验检查偏倚；规范操作改善精确度；区组、随机化及独立重复处理田间环境变异。 |

## 术语

精确度（precision）是规定条件下重复测量结果之间的一致程度，常用标准差、方差或变异系数描述离散。正确度（trueness）描述长期测量中心与参考值的接近程度，与系统误差相关。准确度（accuracy）描述测量值与真值的接近程度，与正确度和精确度都有关，不应简单等同于“均值靠近靶心”，也不赋予它一个自造的百分数。

模型中的 b 已知，实际工作需要用合适的参考物质、校准和质量控制评估偏倚，不能只靠未知样品的一组重复读数识别。校正也不会消除校准、参考值和其他来源的不确定度；误差与测量不确定度不是同一个概念。

## 模拟与动画

- 测量值、弹孔和直方图均为伪随机教学数据，使用固定种子保证可复现。“重新模拟”更换种子。
- 正态样本用 Box–Muller 生成；均匀模型用 U(−√3,√3)，右偏模型用 Exp(1)−1；三者总体均值为 0，标准差为 1。
- 单次误差直方图使用 800 次模拟；均值分布使用 180 组、每组 n 次独立模拟。有限直方图不必完全贴合理论曲线。正态母体的均值仍正态；非正态母体时显示的正态曲线只是参考近似，n 小或偏态强时不应据此断言近似充分。
- 重复提高均值精确度不意味着单次测量的 σ 变小，不保证每次增加样本后均值都更接近真值，也不会消除 b。存在相关性、漂移或非同分布时，σ/√n 关系不能直接照搬。
- 同一土样测定十次是测量重复，不等于十个独立盆栽或田间小区重复；不能据此扩大生物学试验的样本量。
- 打靶用二维位置说明偏移和散布；测定值是一维变量，单位在读数与分布场景中明确标示。四靶为固定比较示例，不是四套真实测定结果。
