# 误差、准确度与精确度

从玉米磷肥试验中的测磷读数出发，固定同一份叶片消解液，再用打靶比喻说明观测值、真值、偏差与散布。田间小区间的真实差异不自动等同于测量误差。

| 顺序 | 场景 | 核心关系 |
| --- | --- | --- |
| 1 | 农业试验 | 玉米磷肥试验 → 叶片取样 → 测磷。先固定同一样品，研究重复测定。 |
| 2 | 定义误差 | 误差 eᵢ = 观测值 xᵢ − 真值 μ，有正有负。本例教学设定 μ=50 mg P/L。 |
| 3 | 测量到打靶 | 真值对应靶心，观测值对应落点。横向偏离与有符号误差成正比，纵向只是辅助位置示意。 |
| 4 | 两类误差 | xᵢ=μ+b+εᵢ，故 eᵢ=b+εᵢ。长期中心 μ+b、样本中心与单次落点应分开看。 |
| 5 | 准确与精确 | 比较偏倚小/大与散布小/大的四种组合。集中不保证准确，样本中心接近靶心也不保证单次结果接近真值。 |
| 6 | 观测与误差分布 | 同一批 xᵢ 逐个减去固定 μ，得到 eᵢ，只有坐标原点与中心改变，形状和离散程度不变。 |
| 7 | 随机误差分布 | ε=e−b=X−μ−b。总误差围绕 b，随机误差围绕 0；可选正态、均匀、右偏模型。 |
| 8 | 重复与均值 | 独立、同分布且方差有限时，E(x̄)=μ+b，SD(x̄)=σ/√n；单次观测的 σ 与 b 不因 n 增大而消失。 |
| 9 | 回到试验 | 测量用质控、校准和规范操作；田间用区组、随机化和独立重复。 |

## 真值与参考值

教学中的真值 μ 是模型已知量。真实样品的真值通常未知；不能用有限次观测的样本均值直接替代真值。在实际质量控制中，常用合适的参考物质与参考值评估测量偏差，同时考虑参考值的不确定度。VIM 的可操作定义以“测得量值减参考量值”表述测量误差，并区分已知参考值与未知真值的情形。

本例用已知 μ 的模拟样品说明定义，不将模拟数值当作真实测磷结果。仪器画面仅为教学外观。

## 换算误差为什么不改变分布形状

对同一被测对象、同一单位和固定真值 μ：

$$e_i=x_i-\mu,\quad \bar e=\bar x-\mu,\quad s_e^2=s_x^2.$$

成对观测的差值、排序与每一组平移后区间中的频数都保持不变。对应的总体关系为：

$$F_e(t)=F_X(t+\mu),\quad E(e)=E(X)-\mu=b,\quad \operatorname{Var}(e)=\operatorname{Var}(X).$$

如果 $X\sim N(\mu+b,\sigma^2)$，则 $e\sim N(b,\sigma^2)$、$\varepsilon=e-b\sim N(0,\sigma^2)$。均匀与右偏分布也满足平移关系；正态不是这一关系成立的前提。

这里说的是**将已经得到的一批观测值换算为误差**。不能扩展成“测量误差不会影响观测分布”：改变测量机制中的 b、σ 或随机误差模型，会改变观测分布。对真值不同的多个小区分别相减，也不是同一个固定平移。换算误差与校正仪器是不同操作。

分布场景以相同单位、相同区间宽度、相同纵轴尺度，显示同一批 800 次观测及其总误差；两条横轴相差 μ=50，移动条形图的轮廓不变。

## 准确度与精确度

精确度（precision）描述规定条件下重复测量的一致性，可用标准差、方差等度量散布。正确度（trueness）描述长期中心接近参考值的程度，与系统误差相关。准确度（accuracy）描述观测值与真值接近的程度，与正确度和精确度都有关；不能只看样本均值，也不自造“准确度百分数”。

本例 b 恒定。真实系统误差也可能表现为比例偏差、漂移等可预测变化。实际工作需用参考物质、校准和质量控制识别偏倚，不能只靠未知样品的重复读数判断 b。校正不消除其他不确定度；误差与不确定度不同。

## 射击与记录

- 弹丸先飞行，再命中；命中后才新增弹孔与记录，短暂纸屑效果消退后弹孔保留。
- 落点超出整块靶板时，不在空气中绘制弹孔；观测表标记“脱靶”，仍保留数值。比较场景的全部落点都计入样本中心。
- 弹孔采用靶面之后的独立绘制层，避免立体视角下被靶盘覆盖。编号对应逐次观测表，点序号可高亮弹孔；旋转、暂停和切换场景不会清除记录。
- “重放本组”清靶并使用同一组数据；“新一组（清靶）”更换随机种子；修改参数后重新生成当前条件下的一组数据，避免旧条件与新条件混记。
- 靶面横向坐标由同一条观测记录的 e=x−μ 计算，未另造一组不相干的水平落点。纵向是额外生成的辅助示意，不是第二个测量量。
- 四靶展示固定 24 发/靶的对照；金色十字为有限样本中心，不等于长期中心。

## 模拟边界

- 伪随机数据固定种子，可复现。正态使用 Box–Muller；均匀使用 U(−√3,√3)；右偏使用 Exp(1)−1。三种基础模型总体均值 0、标准差 1，再乘 σ。
- 随机误差分布使用 800 次模拟；均值分布使用 180 组、每组 n 次独立模拟。有限直方图不必完全贴合理论曲线。
- 正态母体的均值仍正态；非正态母体的均值曲线仅为正态近似，n 小或偏态强时可能不充分。
- 增加重复不保证每次样本均值都更靠近真值。存在相关性、漂移或非同分布时，σ/√n 不能直接套用。
- 同一份土样或消解液重复测定，不等于多个独立盆栽或田间小区重复，不能扩大生物学试验的样本量。
