# 维护说明

界面原则：一个画面、一条知识路径、每步一句提示。详细依据写在文档里，不堆在演示画面上。

- `dist/catalog.json` 管理标题、分类、步骤和路径。
- `dist/assets/world-engine.js` 负责立体几何、透视投影、深度排序、光照、旋转、缩放和粒子动画。
- `dist/assets/world-scenes.js` 包含五套立体场景、环境和教学模型。
- 氮素课件独立加载 `nitrogen-model.js`、`nitrogen-world.js`、`nitrogen.js` 与 `nitrogen.css`，覆盖原有简化场景。九步配有机理侧栏、可展开说明、pH / 施入位置 / 排水 / 氧与碳条件开关；移动端说明位于画面下方并可滚动。模型与数值边界见 [氮素转化机理](氮素转化机理.md)，自动翻步间隔为 11 秒。
- 最小养分律独立加载 `minimum-growth.js` 与 `minimum-growth.css`，五步比较植物与木桶，支持补当前短板与协调供给；背景养分假定充足，模型说明见 [最小养分律说明](最小养分律说明.md)。`lesson.js` 使用目录步骤数量控制播放终点。
- 培养试验三个资源共用 `culture-model.js`、`culture-world.js`、`culture.js` 与 `culture.css`，分别配置 8、9、8 步；新增独立封面、目录与离线文件。玉米调用 `MaizeUptake.drawPlant` 复用叶鞘、叶片、节根和侧根几何，避免另写简化形态。液路、霍格兰配平与模拟数据边界见 [磷效应培养试验](磷效应培养试验.md)。
- 根系吸收专用的 `dist/assets/maize-uptake.js` 覆盖其简化场景，加入曲面叶片、叶鞘、节根—侧根结构、细根毛及根段组织放大；只有该课件载入此模块，默认四步切换整株、根系、根毛放大、整株运输视角。模型形态与比例说明见 [玉米根系模型](玉米根系模型.md)。
- `dist/assets/splitplot-model.js` 负责裂区试验两级随机化与平衡裂区方差分析；`splitplot-world.js` 和 `splitplot.js` 负责场景和七步教学交互。
- `dist/assets/scenes.js` 保留原 SVG 封面的生成函数；当前首页使用 `dist/covers/*-v2.webp` 原创生成图片，构建时仅检查图片存在，不覆盖图片。
- `dist/assets/lesson.js` 管理步骤、参数、连续动画、自动翻步与复位；修改提示语也在这里。
- `dist/assets/normal.js` 与 `normal-scene.css` 为原有正态分布课程。
- `scripts/build.mjs` 生成课程页、封面、浏览器目录和单文件离线版。生成文件应随源码一同提交。

执行 `npm run build`、`npm run check` 后，双击 `dist/index.html` 检查首页。运行 `npm start` 可通过本地服务预览。

当前首页有 10 个资源，其中植物营养 3 个、培养试验 3 个、田间试验 2 个、试验统计 2 个。增减课程时同步修改 `index.html` 中的分类计数、README 资源表、演示模型和步骤提示。页面不依赖 CDN、WebGL 或第三方素材。

## 立体交互

七个课程均可拖动旋转、滚轮缩放；触屏支持单指旋转、双指缩放。画布聚焦时方向键旋转，+ / - 缩放，0 复位视角；画布之外左右键翻步。

新课程中，「动画」控制粒子流动、风动和环境动画；「旋转」自动环绕；底部 ▶ 每 8.5 秒推进一个知识步骤。调整参数会停止自动翻步，场景继续响应。最小养分律、交互作用及区组排列采用平滑过渡；供给百分比是相对满足度，作物高度只是模拟响应，日照、道路、树木等为场景环境，不作为新的试验因素。

裂区试验为七步课件。两个随机按钮分开操作；更换主区随机化时保留各逻辑主区内的施肥顺序，更换副区随机化时保留主区的灌水分配。重新随机会返回相应设计步骤，不在结果页面直接改排已观测的试验。观察比较步骤可点副区查看模拟数据；误差步骤可切换灌水、施肥与交互，并展开完整方差分析表。移动端为避免标注拥挤，仅对选中副区显示单个观测值；灌水误差视图只显示六个主区均值。

未来接入原有 R / Shiny 应用时，可在课程目录中登记已实际发布的应用 URL；R 代码本身不能通过 GitHub Pages 执行，需要独立的 Shiny 服务。
