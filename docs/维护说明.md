# 维护说明

界面原则：一个画面、一条知识路径、每步一句提示。详细依据写在文档里，不堆在演示画面上。

- `dist/catalog.json` 管理标题、分类、步骤和路径。
- `dist/assets/world-engine.js` 负责立体几何、透视投影、深度排序、光照、旋转、缩放和粒子动画。
- `dist/assets/world-scenes.js` 包含五套立体场景、环境和教学模型。
- 氮素课件独立加载 `nitrogen-model.js`、`nitrogen-world.js`、`nitrogen.js` 与 `nitrogen.css`，覆盖原有简化场景。九步配有机理侧栏、可展开说明、pH / 施入位置 / 排水 / 氧与碳条件开关；移动端说明位于画面下方并可滚动。模型与数值边界见 [氮素转化机理](氮素转化机理.md)，自动翻步间隔为 11 秒。
- 最小养分律独立加载 `minimum-growth.js` 与 `minimum-growth.css`，五步比较植物与木桶，支持补当前短板与协调供给；背景养分假定充足，模型说明见 [最小养分律说明](最小养分律说明.md)。`lesson.js` 使用目录步骤数量控制播放终点。
- 培养试验三个资源共用 `culture-model.js`、`culture-world.js`、`culture.js` 与 `culture.css`，分别配置 8、9、8 步；新增独立封面、目录与离线文件。玉米调用 `MaizeUptake.drawPlant` 复用叶鞘、叶片、节根和侧根几何，避免另写简化形态。液路、霍格兰配平与模拟数据边界见 [磷效应培养试验](磷效应培养试验.md)。
- `culture-practical.js` 在主场景之后、控制器之前加载，覆盖准备和定植环节，共 24 个操作画面。`state.operation` 随主步骤复位；自动演示先依次完成操作再翻步。准备期不用已成株的玉米，定苗与定植使用少量展开叶的幼苗几何；后期生长比较仍沿用共用植株模型。
- `culture-equipment.js` 在主场景前加载，提供空心管、气泵、天平与厚壁盆；`maize-harvest.js` 在具体准备场景后加载，提供成熟收获五个操作及称量记录。自动演示在空盘步骤完成去皮后再装样。`world-engine.js` 的 `focusX` 为可选水平观察中心，称量镜头对准天平，其他课件默认 0。苗期模拟表与成熟操作记录必须保持分离。
- 器材之后加载 `maize-grain-geometry.js` 与 `culture-liquid.js`，再加载场景、操作与控制器，避免回退到方块籽粒或短线液流。天平的 `hitRegions` 每帧重新投影，点击时按距目标中心的相对距离选择区域，区分拖动旋转与按钮点击。`grainLoaded`、`grainTared`、`grainRead` 与稳定时间分别控制装样、去皮和读取，不能仅切换到称重页就自动生成记录。
- `hydro-lab.js` 在收获模块之后、控制器之前加载，仅覆盖水培第 2、6 主步骤。配液包含六个操作，pH/通气包含五个操作；`state.hl` 和 `state.ph` 分别保存配制与校准测定状态。原方、实际用量及母液版本必须同时维护，见 [霍格兰配液与 pH 操作](霍格兰配液与pH操作.md)。
- 根系吸收专用的 `dist/assets/maize-uptake.js` 覆盖其简化场景，加入曲面叶片、叶鞘、节根—侧根结构、细根毛及根段组织放大；只有该课件载入此模块，默认四步切换整株、根系、根毛放大、整株运输视角。模型形态与比例说明见 [玉米根系模型](玉米根系模型.md)。
- `dist/assets/splitplot-model.js` 负责裂区试验两级随机化与平衡裂区方差分析；`splitplot-world.js` 和 `splitplot.js` 负责场景和七步教学交互。
- `dist/assets/scenes.js` 保留原 SVG 封面的生成函数；当前首页使用 `dist/covers/*-v2.webp` 原创生成图片，构建时仅检查图片存在，不覆盖图片。
- `dist/assets/lesson.js` 管理步骤、参数、连续动画、自动翻步与复位；修改提示语也在这里。
- 正态分布为九步：形状、对称、拐点、概率、抽样分布、分布比较、两者标准化、累积概率、积分。`normal.js` 管理导航与播放，`normal-sampling-model.js` 提供独立抽样、统计汇总、均值预测反馈、样本量比较及两种标准化，`normal-sampling.js` 绘制第5–7步。抽样页共用一组坐标，默认学生抽样、预测与验证；“自动演示”保留单次、连续和100组累积。`normal-extension.js` 绘制累积概率与积分。详见 [抽样分布与标准化](正态分布标准化与积分.md)。
- `student-t-model.js` 与 `student-t.js` 提供独立的 t 与标准正态比较课件，详见 [模型说明](t分布与标准正态.md)。
- `trial-story-model.js`、`trial-story-scene.js`、`trial-story.js` 与 `trial-story.css` 提供五幕、十五个必做任务与一个完成页。必要操作与正确选择共同解锁下一步，不自动翻步。初判任意选项可继续；本地进度仅存在专用浏览器条目，下载记录不包含个人身份。模型边界、右尾方向与示例数据见 [玉米产量互动闯关](玉米产量互动闯关.md)。
- `scripts/build.mjs` 生成课程页、浏览器目录和单文件离线版，并调用 `sync-resource-docs.mjs` 同步 README、`courses/` 下各资源说明及 [完整文件清单](资源目录.md)。生成文件应随源码一同提交。

执行 `npm run build`、`npm run check` 后，双击 `dist/index.html` 检查首页。运行 `npm start` 可通过本地服务预览。

当前定稿资源以 [课程目录](../courses/README.md) 为准。增减课程时更新 `dist/catalog.json` 和 `sync-resource-docs.mjs` 中的内容说明映射，运行构建后自动同步各处目录、首页总数与分类计数；演示模型和步骤提示也应保持一致。页面不依赖 CDN、WebGL 或第三方素材。

## 立体交互

各课程均可拖动旋转、滚轮缩放；触屏支持单指旋转、双指缩放。画布聚焦时方向键旋转，+ / - 缩放，0 复位视角；普通演示课件在画布之外可左右键翻步。玉米产量闯关课件须完成任务后点击下一步，没有自动播放和按键跳关。

新课程中，「动画」控制粒子流动、风动和环境动画；「旋转」自动环绕；底部 ▶ 每 8.5 秒推进一个知识步骤。调整参数会停止自动翻步，场景继续响应。最小养分律、交互作用及区组排列采用平滑过渡；供给百分比是相对满足度，作物高度只是模拟响应，日照、道路、树木等为场景环境，不作为新的试验因素。

裂区试验为七步课件。两个随机按钮分开操作；更换主区随机化时保留各逻辑主区内的施肥顺序，更换副区随机化时保留主区的灌水分配。重新随机会返回相应设计步骤，不在结果页面直接改排已观测的试验。观察比较步骤可点副区查看模拟数据；误差步骤可切换灌水、施肥与交互，并展开完整方差分析表。移动端为避免标注拥挤，仅对选中副区显示单个观测值；灌水误差视图只显示六个主区均值。

未来接入原有 R / Shiny 应用时，可在课程目录中登记已实际发布的应用 URL；R 代码本身不能通过 GitHub Pages 执行，需要独立的 Shiny 服务。



田间场景共用 `field-assets.js`：节茎、弯曲叶片、雄穗与果穗的轻量玉米几何，四周道路与拖拉机，外围保护行、进水渠、阀门、排水沟和道路跨沟板。保护行不计入试验重复。随机区组沿区组边缘管线向各小区独立供水；裂区按主区设进水阀与田埂，副区共享所属主区灌水处理，出水沿区间沟汇入外围排水沟。地形、管渠及植株高度为教学尺度，不据株高计算模拟产量。

全部玉米地上部统一由 `maize-shoot.js` 提供分生育期模型：幼苗 3 片展开叶与卷心叶、营养生长期 8 叶与叶鞘茎节、田间生殖期与成熟期 10 叶并有雄穗和果穗。近景使用细分叶面、叶脉和叶鞘，田间使用较低细分以控制绘制量。根系吸收与培养试验继续保留原来的节根、侧根和根毛结构；成熟穗保留独立籽粒模型，采穗前以闭合苞叶和花丝覆盖，脱粒环节显示裸穗。生长差异仍是教学示意，不据株高推断产量。

玉米产量课件第2版的历史汇总与查表由 `trial-story-teaching.js` 提供：首幕先呈现大量历史小区，240条同源记录实际分组；已知SE的标准化保留面积，并要求查对0到z积分表、求出右尾。`trial-story-model.js` 提供历史样本与变换模型；当前进度键为v4，旧版条目保留。课堂措辞先提出问题，再用图形与选择解释，不提供学生的预设回答。

Gosset对照由 `trial-story-gosset.js` 提供。第9步先累积已知/估计分母的成对结果，再揭示t曲线；自由度用固定四小区例子解释，不要求拖动或自由度专门答题。第10步用两栏MathML公式说明Z方差归一化、T额外随机因子与n的关系，下方只有两条对比曲线。第15步将原场景画布移入四面板中的田间卡片，另用Canvas绘制本批t曲线；离开该步时须把原画布移回主场景，保持旋转与命中区域有效。

第4版中，第10步将原场景画布移入 `formula-comparison` 内的曲线区域；切换至其他步骤前必须将原画布移回主场景。自由度交互与Z换刻度动画的旧状态不再参与解锁；第10步只要求比较n＝4与n≥30并回答两式分母区别。
