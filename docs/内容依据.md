# 内容依据与模型边界

课程范围依据本地《植物营养研究法的目录.txt》中的培养研究、田间研究、试验设计与统计主题确定。本版不声称逐页复现教材。

| 课件 | 依据与边界 |
| --- | --- |
| 根系吸收 | 展示溶液、根表迁移、跨膜吸收和木质部运输的概念路径。离子图示不表示所有养分共用同一载体；未模拟电化学梯度和根际反应。可参考 [MU Extension: Soils, Plant Nutrition and Nutrient Management](https://extension.missouri.edu/publications/mg4)。 |
| 最小养分律 | 使用供给相对需求的百分比，不比较不同元素的绝对质量。生长限制取各养分相对满足度的最小值；忽略毒害、替代关系、水分、温度等因素。参考 [Missouri Fertilizer Control Board](https://www.mofcb.com/applying-nutrients-at-the-right-rate-leads-to-increased-economic-and-agronomic-productivitiy/)。 |
| 氮素转化 | 参考 [University of Minnesota: Understanding Nitrogen in Soils](https://bwsr.state.mn.us/sites/default/files/2019-07/UnderstandingNitrogenCycleinSoils.pdf)。图中只展示部分主要路径，省略固定、挥发、微生物同化等；硝化和反硝化不是相同环境条件下的必然连续过程。 |
| 随机区组 | 每区组含全部 4 个处理，每个处理出现 1 次；各区组独立随机。区组内条件相近，区组间允许存在梯度。参考 [Penn State STAT 503: Blocking](https://online.stat.psu.edu/stat503/Lesson04) 与 [Iowa State: Randomized Complete Block Design](https://iastate.pressbooks.pub/quantitativeplantbreeding/chapter/randomized-complete-block-design/)。 |
| 裂区试验 | 灌水两水平为主区、施肥三水平为副区，三个区组、两级随机化。主区误差 df=2，副区误差 df=8。试验结构、模拟响应与实际计算的方差分析见 [裂区试验说明](裂区试验说明.md)。 |
| 正态分布 | 沿用用户已有课件。μ 为位置参数，σ 为标准差；中央 95% 使用 1.9599639845σ，而非近似的 2σ。旋转只是观察视角，不引入第二个随机变量；不是所有实测数据都服从正态分布。 |
| 氮磷交互作用 | 四个均值固定为 20、40、35、55+γ；交互对比为 (55+γ−35)−(40−20)=γ。γ 可在 −25 到 25 调节。图形用于识别效应随另一因素水平而变，不代替方差分析或显著性检验。 |

首版 SVG 封面保留；当前首页使用原创生成的立体科学主题图片，详见 [封面设计](封面设计.md)。图中颜色、尺度、木桶高度和田间梯度为教学简化，未使用真实产量、肥料用量或试验观测数据。

2026-10-31：五个新课件改为可旋转的三维几何场景。粒子表示迁移路径而非真实离子数量，流动速度滑块仅改变演示节奏；膜上转运蛋白为独立放大的示意，非尺度一致的根组织结构。木桶旁植物高度为相对限制因子的可视化，不构成剂量—产量预测。氮素场景将可能发生于不同微环境的路径并列展示，不表示它们必然同时、等速发生。田间日照、云、道路和树木为环境布景；不以画面阴影差异改变模拟处理效果。
