# 裂区试验：灌水主区 × 施肥副区

课件：[在线演示](https://lidong-huang.github.io/plant-nutrition-lab/lessons/splitplot.html) · [离线单文件](../dist/downloads/splitplot.html)

## 试验结构

灌水 A 设置 W1、W2 两个水平，分配到主区；施肥 B 设置 F1、F2、F3 三个水平，分配到副区。灌水水平用相对低、高表示，未指定实际灌水量或施肥量。

为讲清重复与误差，本课件采用三个区组作示例：

- 每区组有两个主区，W1 和 W2 各一次。
- 每主区分三个副区，F1、F2、F3 各一次。
- 总计 3 × 2 = 6 个主区，3 × 2 × 3 = 18 个副区。
- 每个 W×F 组合在每个区组出现一次，跨区组共三次重复。

三个区组用于结构演示，不表示任何实际研究采用三次重复就一定具有足够检验功效。

## 七步过程

1. **研究问题**：灌水通常比施肥更难在小范围内改变，因此先在较大的单元上安排灌水。
2. **区组主区**：沿田间差异划分三个区组，再把各区组分成两个主区。
3. **主区随机**：各区组内独立随机分配 W1、W2。点击“主区随机”，整主区连同内部副区一起换位。
4. **副区随机**：在每一个主区内部，独立随机分配 F1、F2、F3。点击“副区随机”不改变灌水布局，也不要求不同主区采用同样的施肥顺序。
5. **实施处理**：独立阀门控制主区灌水，共同水路覆盖其三个副区；肥料分别施入副区。田埂、缓冲带和隔水措施用于降低处理间干扰，画面仅为其原理示意。
6. **观察比较**：每个副区有一个模拟响应。可点击副区查看区组、灌水、施肥与响应；切换 A、B、A×B 比较相应均值或效应。
7. **两层误差**：灌水在主区层随机化，用主区误差检验；施肥与交互作用在副区层检验，用副区误差。

物理单元是嵌套的，但施肥水平在每个灌水水平都重复出现，两个处理因素是交叉的 2×3 析因组合；不能把 F1、F2、F3 解释为各主区内含义不同的嵌套处理。

## 实验单元与伪重复

灌水的实验单元是主区。W1 和 W2 各有三个独立主区；同一主区里的三个副区共享该主区的随机分配和环境误差，不能把它们当作灌水的三次独立重复。因此每个灌水水平的独立重复是 3，而非 9。

施肥的实验单元是副区。每个灌水主区内都有三个施肥水平，形成主区内的细尺度比较。只增加同一副区内的植株测量数，也不会增加施肥处理的独立重复数。

## 方差分析结构

采用完整、平衡、随机区组裂区试验的经典模型；区组及主区误差视为随机来源，灌水和施肥为固定因素。主区误差可表示为区组×灌水的变异；副区误差为剩余的副区层变异。

| 来源 | 自由度 | F 检验分母 |
| --- | ---: | --- |
| 区组 R | r−1 = 2 | 本课件不检验区组 |
| 灌水 A | a−1 = 1 | MS(Eₐ) |
| 主区误差 Eₐ | (r−1)(a−1) = 2 | — |
| 施肥 B | b−1 = 2 | MS(Eᵦ) |
| A×B | (a−1)(b−1) = 2 | MS(Eᵦ) |
| 副区误差 Eᵦ | a(r−1)(b−1) = 8 | — |
| 总计 | rab−1 = 17 | — |

F(A)=MS(A)/MS(Eₐ)，F(B)=MS(B)/MS(Eᵦ)，F(A×B)=MS(A×B)/MS(Eᵦ)。课件从 18 个模拟观测实际计算 SS、df、MS 和 F，而非预填结果。单看均值差或 F 数值不等于已完成显著性判断；本课件不作真实农艺结论。

模拟响应由区组、灌水、施肥、交互效应、主区共同偏差与副区偏差组合生成；数值固定以便重排布局时保持同一组示例可比较。重排是设计过程示意，不表示真实田间重新随机分配后产量必然不变。
