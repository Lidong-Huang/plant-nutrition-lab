# 土壤中的氮素转化：机理与演示边界

课件采用九步结构。每步先看氮的形态，再看发生条件与去向；各步表示不同情景，不是同一团土壤必然连续完成的反应链。

本次画面采用土壤微区：菌丝接触含氮残体、胞外酶参与分解、微生物细胞摄取底物和释放产物；硝化分别展示氨氧化与亚硝酸氧化功能群，反硝化展示缺氧、有可用有机碳时的还原路径。微生物形状和细胞内部结构均为放大示意，颜色区分功能，不用于鉴定具体菌种或表示实际尺寸。矿化中的细胞、菌丝与酶不是只能由某一种微生物提供，脲酶也可来自植物残体等来源。

动态颗粒表示氮素形态与迁移，颗粒数、粒径、移动速度及出现顺序不代表实测质量、浓度、反应时间或完整化学计量。水解需要水，不以氧气作为该反应的必需底物；硝化的氧气输入与氢离子释放另外表示。硝化功能群可包含细菌和古菌，亦存在全程氨氧化（comammox）微生物，因此两组细胞是经典两步路径的教学拆分，不是“必定由两个固定菌种完成”。

挥发用 NH₃ 从溶液向空气扩散的分子与气泡轮廓表示；淋洗用水体包裹溶解态 NO₃⁻，跨越根层边界后才进入收集器；反硝化按 NO₃⁻ → NO₂⁻ → NO → N₂O → N₂ 的路径显示，在有氧或缺少可利用有机碳时弱化。几种气体不得混为一种氮损失。

图示依据：[明尼苏达大学氮循环讲解](https://swroc.cfans.umn.edu/research/soil-water/nitrogen-cycle)、[佛罗里达大学土壤氮转化概述](https://ask.ifas.ufl.edu/publication/SS684)、[全程硝化原始研究](https://www.nature.com/articles/nature16459)。

## 1. 分清形态

有机氮存在于土壤有机质、残体和微生物体内。尿素是另一种含氮输入。植物通常主要吸收铵态氮 NH₄⁺ 与硝态氮 NO₃⁻。形态改变属于转化；氮越过当前观察系统的边界，才计为该系统的输出。

## 2. 有机氮矿化

微生物及其酶分解含氮有机物，将有机氮释放为氨态氮；多数土壤溶液中主要以 NH₄⁺ 存在。这一释放过程常称氨化，是有机氮矿化的一部分。温度、水分、底物组成会影响过程。

反向箭头表示微生物吸收 NH₄⁺、NO₃⁻ 合成自身有机物，形成生物固持。矿化与固持可以同时发生。固持不等于把空气中 N₂ 转化为含氮化合物的生物固氮。

## 3. 尿素水解

尿素溶解后，在脲酶作用下发生水解，形成 NH₄⁺ / NH₃ 等产物。这与需要氧的硝化不同。尿素颗粒附近 pH 可暂时升高，增加 NH₃ 的相对比例。表施让 NH₃ 更接近大气；混入土层增加接触、滞留与缓冲机会。画面可切换表施、混入土层观察位置差异。

## 4. 硝化

有氧条件下，硝化微生物将氨 / 铵经 NO₂⁻ 氧化为 NO₃⁻：

NH₄⁺ → NO₂⁻ → NO₃⁻

总体计量关系可表示为：NH₄⁺ + 2 O₂ → NO₃⁻ + 2 H⁺ + H₂O。产生 H⁺ 可对酸化有贡献。硝化并非把铵直接变成气体；形成的硝酸盐可以被吸收，也可能在后续排水或缺氧情景中损失。

## 5. 吸收与保留

植物可以吸收 NH₄⁺ 和 NO₃⁻。带正电的 NH₄⁺ 常被土壤带负电的交换位点吸附；NO₃⁻ 在许多土壤中较少被交换吸附，更多存在于溶液中。吸附是相对保留，不是永久锁住：NH₄⁺ 可再交换、被吸收或转化，某些矿物也可能发生层间固定。不同土壤的行为存在差异。

## 6. 氨挥发：从溶液到空气

NH₄⁺ ⇌ NH₃ + H⁺；NH₃(aq) → NH₃(g)

逸散到空气的是 NH₃，不是“铵离子气体”。提高施肥点 pH，会增加平衡中的 NH₃ 比例。课件橙色粒子从土表进入空气，风向箭头表示空气交换。

滑块计算约 25°C、pKₐ≈9.25 时，水溶液中 NH₃ 占 NH₄⁺ + NH₃ 的比例：

f(NH₃) = 1 / [1 + 10^(9.25 − pH)]

这是溶液形态分配，不是田间挥发损失率。例如 pH=9.25 时比例为 50%，并不表示施入氮损失 50%。温度、土壤缓冲性、含水率、风、施入深度与时间等共同影响实际损失。混入土层按钮在固定 pH 下不改变上述比例，只降低示意的逸散强度；该强度没有田间定量含义。

## 7. 硝态氮淋洗：随排水越过根层

雨水或灌水先补充土壤蓄水；本情景在形成向下排水后，溶解的 NO₃⁻ 随水越过当前根层下界。画面蓝色水滴为载体，内部青色粒子为 NO₃⁻，下方收集器表示渗漏液。切换“蓄水 / 排水”比较是否出现出口。

这条箭头表示迁移，不是化学反应，也不是气体逸散。根层以下的硝态氮不一定立即到达地下水。实际结果受土壤质地、旁路流、根深、排水量和植物吸收等影响。图中根层边界是概念边界，不对应实际厘米数。

课件突出常见的硝态氮淋洗；并不表示 NH₄⁺ 绝不会淋失，也未涵盖溶解尿素、有机氮等全部迁移形式。

## 8. 反硝化：缺氧条件下的微生物还原

NO₃⁻ → NO₂⁻ → NO → N₂O → N₂

缺氧时，部分微生物利用硝酸盐等作为电子受体，并利用有机碳等电子供体完成还原。课件可切换氧条件与可用碳，观察紫色气态氮出口的变化。这个条件开关是定性示意，默认硝酸盐与适宜微生物存在，并非完整动力学模型。

饱和、积水有利于形成缺氧环境，但不能只凭有积水就判定反硝化必然旺盛。反应不一定完全进行到 N₂，可能释放 N₂O 等中间产物。N₂O 也有其他土壤来源；反硝化不是 NH₃ 挥发。

## 9. 对比三条损失路径

| 过程 | 主要起点 | 输出形态与方向 | 关键条件 |
| --- | --- | --- | --- |
| 氨挥发 | NH₄⁺ / NH₃ 平衡体系 | NH₃ 气体 → 空气 | pH、表施位置、温度与空气交换等 |
| 硝态氮淋洗 | 溶解的 NO₃⁻ | 随排水 → 根层以下 | 形成向下排水、存在可迁移硝酸盐 |
| 反硝化 | NO₃⁻ | N₂O / N₂ 等气体 → 空气 | 缺氧、硝酸盐、电子供体和适宜生物条件 |

对比页每次聚焦一种情景；不同微环境可能并存多条路径，画面不将其混为必然同步的过程。粒子数量、速度、箭头、气泡和收集器液位均用于表达路径，不表示质量守恒计算、实测氮量或损失预测。暂停、旋转、缩放与离线单文件版均保留。
